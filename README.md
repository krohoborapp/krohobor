# Дима Крохобор — возврат приложений на iPhone

Программа для Mac, Windows и Linux. Помогает скачать приложения, которые раньше были на твоём Apple ID (в том числе удалённые из App Store, банки и их маскировки), и поставить их на iPhone по кабелю или по Wi‑Fi.

Telegram-канал: https://t.me/krohobortv · чат для вопросов: https://t.me/+DpS_lfSl1Mo3NjU6

## Скачать

Последняя версия — на странице [Releases](https://github.com/krohoborapp/krohobor/releases/latest):

- **Mac** — `DimaKrohobor-<версия>.dmg` (Apple Silicon и Intel, macOS 11+)
- **Windows** — `DimaKrohobor-<версия>-windows.zip`, распаковать и запустить «Дима Крохобор.exe»
- **Linux** — `DimaKrohobor-<версия>-linux.zip`

Дальше программа обновляется сама: при запуске покажет «Вышла версия …» и кнопку «Обновить».

## Что умеет

- Рабочий стол с живым iPhone: видно, подключён ли телефон, что на нём стоит, и как ставится приложение.
- Вход в Apple ID с кодом подтверждения. Пароль уходит только в Apple, программа его не хранит.
- Поиск по-русски и по-английски, с опечатками, неправильной раскладкой и ссылками из App Store.
- Каталог российских приложений по категориям: маскировки собраны под настоящим названием, видно, что есть в App Store, а что удалено.
- Мои покупки: вся история Apple ID, сравнение с iPhone, «Сохранить удалённое» одной кнопкой.
- Любая версия приложения с проверкой, подойдёт ли она к iOS телефона.
- Библиотека IPA: установка без перекачивания, свои IPA, удаление в Корзину.
- Проверка системы, драйвер Apple для Windows, отчёт об ошибке для чата (без пароля, почта скрыта).

## Где что лежит у пользователя

- Скачанные приложения: `Документы/Дима Крохобор/Моя библиотека IPA`
- Журнал и отчёты: `Документы/Дима Крохобор/Журнал`

## Как обновлять

### Каталог маскировок — `catalog.txt`

Открой файл на GitHub, нажми карандаш, допиши строку в нужную категорию, нажми «Commit changes». Программы подписчиков подтянут каталог при следующем запуске.

```
## Мессенджеры и соцсети
Макс (Yaqin Messenger): 6812428354 | макс, max, yaqin, ечин | 2026-11-26
```

- `## Категория` начинает категорию.
- В скобках — как приложение называется в App Store (у оригинала скобок нет).
- После двоеточия — ID из ссылки App Store (`apps.apple.com/…/id6812428354`).
- После `|` — слова для поиска через запятую.
- Дата `ГГГГ-ММ-ДД` — когда добавил. Две недели такое приложение отмечено «Новое», а у всех появляется плашка «Вышли новые маскировки» со ссылкой на канал.
- Можно добавить ссылку на иконку `| https://…png`, если App Store её не отдаёт.

Каждую ночь GitHub сам проверяет все приложения каталога (есть в App Store или удалено, версия, иконка) и кладёт результат в ветку `data`. Ничего делать не нужно.

### Ссылки на канал и чат — `links.json`

Поменялась ссылка — поправь её в `links.json`. У всех обновится при следующем запуске программы, новая версия не нужна.

### Новая версия программы

Создай релиз с тегом `v<версия>` (например `v1.4.0`): «Releases» → «Draft a new release» → «Choose a tag» → вписать тег → «Publish release». GitHub сам соберёт версии для Mac, Windows и Linux и приложит их к релизу. Программы подписчиков увидят обновление при запуске.

## Сборка вручную

Нужен Go 1.22+ и папка [IPA_Downloader](https://github.com/kda2495/IPA_Downloader) (из неё берутся ipatool-cpp, libimobiledevice и AppsList.txt).

```
python3 packaging/build.py 1.4.0 ../IPA_Downloader-main ../release
```

На Mac после сборки запусти `Собрать DMG.command` — появятся `DimaKrohobor-1.4.0.dmg` и `DimaKrohobor-1.4.0-mac.zip`.
