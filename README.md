# Дима Крохобор — возврат приложений на iPhone

Программа для Mac, Windows и Linux. Скачивает приложения, которые раньше были на твоём Apple ID, в том числе удалённые из App Store банки и их маскировки, и ставит их на iPhone по кабелю или по Wi‑Fi.

Telegram-канал: https://t.me/krohobortv · чат для вопросов: https://t.me/+DpS_lfSl1Mo3NjU6

## Скачать

Последняя версия — на странице [Releases](https://github.com/krohoborapp/krohobor/releases/latest):

- **Mac** — `DimaKrohobor-<версия>.dmg`. Подходит для Mac на M‑процессорах и Intel, macOS 11 и новее.
- **Windows** — `DimaKrohobor-<версия>-windows.zip`. Windows 10 и 11.
- **Linux** — `DimaKrohobor-<версия>-linux.zip`.

Дальше программа обновляется сама: при запуске покажет «Вышла версия …» и кнопку «Обновить».

## Как поставить

**Mac.** Открой DMG и перетащи «Дима Крохобор» в «Программы». Программа бесплатная и не подписана у Apple, поэтому первый раз её нужно разрешить:

1. Запусти программу. Mac напишет, что не может её проверить, — нажми «Готово».
2. Открой «Системные настройки» → «Конфиденциальность и безопасность», прокрути вниз до строки про «Дима Крохобор» → «Всё равно открыть» → введи пароль от Mac.
3. Дальше программа запускается обычно. Если Mac спросит про подключение аксессуара — «Разрешить».

На macOS 14 и старше проще: правой кнопкой по программе → «Открыть» → «Открыть».

**Windows.** Сначала обязательно распакуй архив: правой кнопкой мыши → «Извлечь всё…» → «Извлечь». Прямо из архива программа не запустится. Потом открой распакованную папку и запусти «Дима Крохобор.exe». Если Windows покажет синее окно «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае». При первом запуске программа поможет поставить драйвер Apple, чтобы компьютер видел iPhone.

**Linux.** Распакуй архив и запусти `dimakrohobor`. Нужна служба `usbmuxd`.

Дальше программа сама проведёт по настройке: вход в Apple ID и подключение iPhone.

## Что умеет

- Рабочий стол с живым iPhone: видно, подключён ли телефон, что на нём стоит и как ставится приложение.
- Вход в Apple ID с кодом подтверждения. Пароль уходит только в Apple, программа его не хранит.
- Поиск по-русски и по-английски, с опечатками, неправильной раскладкой и ссылками из App Store.
- Каталог российских приложений по категориям: маскировки собраны под настоящим названием, видно, что есть в App Store, а что удалено.
- Мои покупки: вся история Apple ID, сравнение с iPhone, «Сохранить удалённое» одной кнопкой.
- Любая версия приложения с проверкой, подойдёт ли она к iOS телефона.
- Библиотека IPA: установка без перекачивания, свои IPA, удаление в Корзину.
- Проверка системы и отчёт об ошибке для чата (без пароля, почта скрыта).
