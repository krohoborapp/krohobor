**Что нового в 1.4.6**

- «Что нового» теперь открывается прямо в программе — не нужно идти на GitHub
- История «Моих покупок» сохраняется: после перезапуска список сразу на месте
- Обновление на Windows больше не спотыкается о занятые файлы, а при повторе не качает заново
- «Скачать и поставить»: сначала видно скачивание на карточке приложения, к телефону — когда файл реально уходит на iPhone
- С карточки приложения есть кнопка «Назад»
- Повторное нажатие «Поставить» не запускает вторую установку

**Как поставить**
Mac — скачай DMG, перетащи в «Программы», первый запуск через правую кнопку → «Открыть».
Windows — скачай windows.zip, распакуй (правой кнопкой → «Извлечь всё…») и запусти «Дима Крохобор.exe».
Если программа уже стоит — нажми «Обновить», она обновится сама.
