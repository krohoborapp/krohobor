# Как обновлять программу и каталог

## Каталог маскировок — `catalog.txt`

Открой `catalog.txt` на GitHub, нажми карандаш, допиши строку в нужную категорию, нажми «Commit changes». Программы у всех подтянут каталог при следующем запуске, новая версия не нужна.

```
## Мессенджеры и соцсети
Макс (Yaqin Messenger): 6812428354 | макс, max, yaqin, ечин | 2026-11-26
```

- `## Категория` начинает категорию.
- В скобках — как приложение называется в App Store. У оригинала скобок нет.
- После двоеточия — ID из ссылки App Store (`apps.apple.com/…/id6812428354`).
- После `|` — слова для поиска через запятую.
- Дата `ГГГГ-ММ-ДД` — когда добавил. Две недели такое приложение отмечено «Новое», а у всех появляется плашка «Вышли новые маскировки» со ссылкой на канал.
- Можно добавить ссылку на иконку `| https://…png`, если App Store её не отдаёт.

Каждую ночь GitHub сам проверяет все приложения каталога (есть в App Store или удалено, версия, иконка) и кладёт результат в ветку `data`. Ничего делать не нужно.

## Ссылки на канал и чат — `links.json`

Поменялась ссылка — поправь её в `links.json`. У всех обновится при следующем запуске, новая версия не нужна.

## Новая версия программы

1. В файле `VERSION` меняется номер, например `1.4.1` → `1.4.2`.
2. GitHub сам собирает версии для Mac, Windows и Linux (около 5 минут, видно во вкладке Actions) и создаёт **черновик** релиза. Его видишь только ты.
3. Скачай из черновика DMG или архив для Windows и проверь.
4. Всё в порядке — открой черновик в Releases → карандаш → **Publish release**. С этой минуты программы у всех покажут «Вышла версия …».

## Сборка вручную

Нужен Go 1.22+ и папка [IPA_Downloader](https://github.com/kda2495/IPA_Downloader) (из неё берутся ipatool-cpp, libimobiledevice и AppsList.txt).

```
python3 packaging/build.py 1.4.2 ../IPA_Downloader-main ../release
```

На Mac после сборки запусти `Собрать DMG.command` — появятся DMG и `auto-update-mac.zip` (архив для кнопки «Обновить» в программе, людям его качать не нужно). Своё окно программы добавится, если на Mac стоят Xcode Command Line Tools; без них программа будет открываться в браузере.
